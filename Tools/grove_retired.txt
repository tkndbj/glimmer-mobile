# Every grove piece id that has ever shipped, and may never be used again.
#
# WHY THIS FILE EXISTS. On 2026-09-11 the whole grove catalogue was replaced: the
# CraftPix isometric sheets went and a village rendered from KayKit models took their
# place, and every player's grove was reset with it. None of that makes an id safe to
# reuse. A piece id is written into save files twice over — into the stock and into
# every tile holding one — so a rolled-back client, a device that has not synced, or a
# backup restored next year can still name one of these, and an id pointed at a
# different object resolves to a thing nobody bought and nobody placed.
#
# Ids in the replacement catalogue were chosen around this list; where one collided it
# was renamed (well -> village_well, pine -> pine_tree, and six others). A reused
# id here is refused by grove_roster.read() rather than reported, because there is no
# reading of it that is correct. It is the same rule, and the same list, that content.py
# keeps as RETIRED_BLOCKS and that CLAUDE.md keeps for every retired mode, chapter,
# level and lesson id.
#
# THE IDS BELOW ARE SORTED AND THE HEADER IS NOT PART OF THAT. This file is maintained
# by hand, and a past edit sorted the whole of it — which left these sixteen lines in
# alphabetical order and the explanation unreadable. Sort the ids, never the file.
